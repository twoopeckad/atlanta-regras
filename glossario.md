# Glossário

Termos que aparecem nas regras e o que eles querem dizer na Atlanta.

| Termo | Significado |
| --- | --- |
| **RP (roleplay)** | Interpretar um personagem como se a cidade fosse real. |
| **Allowlist** | Prova de regras que libera a sua entrada na cidade. Pode ser retirada por punição. |
| **Personagem** | A pessoa que você interpreta. Ela não é você: tem nome, história e limites próprios. |
| **OOC / fora do RP** | Tudo o que é do mundo real: você, sua casa, o Discord, a live. |
| **Quebrar o personagem** | Falar ou agir como jogador no meio do roleplay. |
| **Amor à vida** | Agir com medo real de morrer, como agiria na vida real. |
| **RDM** | Matar ou ferir alguém sem motivo construído no roleplay. |
| **VDM** | Usar o veículo como arma sem motivo construído no roleplay. |
| **Metagaming** | Usar no jogo uma informação que você conseguiu fora dele. |
| **Powergaming** | Fazer algo impossível na vida real ou não dar chance de reação ao outro. |
| **Combat logging** | Sair do jogo para escapar de uma situação. |
| **Revenge kill (RK)** | Voltar depois de morrer para se vingar com o que lembra da ação. |
| **Cop bait** | Provocar a polícia sem motivo ou levá-la para uma emboscada preparada. |
| **Forçar RP** | Obrigar outra pessoa a entrar numa cena que ela não procurou, sem motivo. |
| **Dark RP** | Roleplay com temas pesados e proibidos, como abuso sexual e tortura explícita. |
| **Dar voz** | Anunciar de forma clara a abordagem: "perdeu", "mão na cabeça", "parado, polícia". |
| **Rendido** | Quem recebeu a voz e está sob a mira de uma arma. |
| **Ação** | Qualquer atividade criminosa marcada: roubo a loja, banco, caixa eletrônico, sequestro. |
| **Porte da ação** | Tamanho da ação: pequeno, médio ou grande. Define pessoas, reféns e polícia. |
| **Fuga limpa** | Fugir sem atirar e sem usar arma, só dirigindo ou correndo. |
| **Apoio (QRR)** | Membros que chegam para ajudar quem já está numa situação. |
| **Área segura (safezone)** | Local onde nenhuma ação criminosa pode acontecer. |
| **Membro setado** | Jogador que faz parte oficialmente da facção, com cargo no painel. |
| **Farm** | Coleta de matéria-prima da facção. |
| **Desmanche** | Local onde a facção desmonta veículos roubados. |
| **Caixa 2** | Vender ou comprar qualquer coisa da cidade com dinheiro real. |
| **Clipe** | Gravação curta da sua tela. É a principal prova numa denúncia. |
| **Ticket** | Atendimento privado com a staff, aberto no Discord. |
